# 포지셔닝 · 저작권 · 수익화

Knotty가 **무엇이고 무엇이 아닌지**, 그리고 그 정의가 왜 저작권·수익 모델과 직결되는지를 정리한 문서입니다.

---

## 1. 한 줄 정의

> **Knotty는 뜨개 영상을 따라 뜨기 쉽게 정리해 주는 도구입니다. 도안을 만들어 파는 서비스가 아닙니다.**

타깃은 **도안이 필요한 초보자**, 그중에서도 **기법이 익숙하지 않아 영상 중간에 자꾸 되감는 사람**입니다.
"유튜브 댓글에 누군가 정리해 둔 단별 요약" — 그게 원래 하고 싶었던 것이고, 그 이상으로 넘어가지 않는 것이 이 서비스의 안전선입니다.

---

## 2. 저작권: 무엇이 위험하고 무엇이 안전한가

> ⚠️ 법률 자문이 아닙니다. 리스크를 줄이는 실무 원칙입니다. 실제 분쟁 가능성이 보이면 전문가 상담이 필요합니다.

### 진짜 위험한 지점

노트에 적었던 걱정("이미 공개된 영상과 별개로 도안을 판매하고 있는데")이 정확합니다.
**위험의 본질은 요약 자체가 아니라 유료 상품의 대체재가 되는 것**입니다.

창작자가 영상은 무료로 공개하고 **서술형 도안은 따로 판매**하는 구조라면,
Knotty가 그 영상에서 완결된 서술형 도안을 뽑아 무료 제공하는 순간 **판매 상품을 직접 잠식**합니다.
저작권 판단 이전에, 창작자가 화를 낼 이유가 여기에 있습니다. 그리고 실제 분쟁은 대개 여기서 시작됩니다.

부차적으로:
- 자막 텍스트를 대량으로 그대로 재현하면 복제로 볼 여지가 있습니다 (요약·재구성은 상대적으로 안전)
- 자막 스크래핑은 유튜브 이용약관과 마찰이 있을 수 있습니다

### 리스크를 줄이는 5가지 원칙

**① 어휘를 바꾼다 — "도안을 만든다" → "영상을 정리한다"**

같은 결과물이라도 스스로를 뭐라고 부르는지가 분쟁의 출발점을 바꿉니다. 아래 3번 카피 가이드 참고.

**② 영상 없이는 완결되지 않게 만든다**

이게 가장 실효성 있는 장치입니다. Knotty의 결과물을 **독립적으로 쓸 수 있는 도안**이 아니라
**영상을 보면서 쓰는 내비게이션**으로 설계합니다.

- 각 단에 **타임스탬프를 노출**하고 클릭 시 해당 시점으로 이동
  → ⚠️ 스키마에 `timestamps` 필드는 있으나 **값이 전부 0이라 실제로는 동작하지 않습니다.**
  이 원칙을 뒷받침하는 가장 중요한 장치이므로 [ROADMAP.md P2-0](ROADMAP.md)에서 최우선으로 복구합니다
- 상세 설명은 자세히 쓰되, **영상을 대체할 만큼 세밀한 손동작 서술은 지향하지 않음**
- 결과 카드 상단에 "이 정리는 원본 영상과 함께 보도록 만들어졌습니다" 고지

**③ 원본으로 트래픽을 되돌린다**

Knotty가 창작자에게 **손해가 아니라 이득**이 되게 만드는 구조입니다.
- 영상 링크 · 채널 링크 · 썸네일 (구현 완료)
- **도안 판매 링크** — 설명란에서 추출해 눈에 띄게 배치 (P2-2)
- **실 구매 링크** — 채널 운영 쇼핑몰 우선

> 도안 판매 링크를 "구석에 작게"가 아니라 **"정식 도안 구매하기" 버튼으로 크게** 배치하세요.
> 창작자 입장에서 Knotty가 판매 채널로 보이면 관계가 완전히 뒤집힙니다.

**④ 창작자 opt-out 창구를 연다**

"내 영상은 빼주세요"라는 요청을 받는 채널(이메일/폼)을 만들고, **요청 시 즉시 삭제**합니다.
- `patterns`에 `is_hidden` 플래그, `creators`에 `opt_out` 플래그
- 이 창구의 존재 자체가 선의의 증거이며, 실제 분쟁의 90%는 여기서 조용히 끝납니다

**⑤ 도안으로 직접 돈을 벌지 않는다**

도안 열람은 무료, 수익은 준비물 제휴·광고에서. 이 원칙을 문서와 서비스에 명시합니다.
"AI가 정리한 도안을 판매"하는 순간 모든 방어 논리가 무너집니다.

### 정리

| 하는 것 | 하지 않는 것 |
|---|---|
| 단별 흐름 요약 · 기법 약어 정리 | 영상 없이 완결되는 도안 배포 |
| 타임스탬프로 영상 내비게이션 | 자막 원문 대량 재현 |
| 원본 영상·채널·판매처로 링크 | 도안 자체의 유료화 |
| 창작자 요청 시 삭제 | 창작자 표기 없는 재배포 |

## 3. 카피 가이드

| 위치 | 현재 | 변경안 |
|---|---|---|
| 메인 설명 | "뜨개질 유튜브 영상 링크를 입력하면 AI가 오타를 교정하여 깔끔한 도안으로 바꿔드립니다" | **"뜨개질 유튜브 영상 링크를 넣으면, 따라 뜨기 쉽게 단별로 정리해 드려요"** |
| 버튼 | "도안 추출하기" | **"영상 정리하기"** |
| 로딩 | "…오타를 교정하는 중입니다" | "영상을 단별로 정리하는 중입니다" |
| 카드 푸터 | "Generated by Knotty AI" | **"원작자: {채널명} · 정리: Knotty 🧶"** |
| 댓글 내보내기 말미 | — | **"— scripted by Knotty 🧶"** |

노트에 적었던 "뜨개질 유튜브 영상 링크를 입력해서 나만의 서술형 도안을 만들어보세요!"는 톤은 좋지만
**"도안을 만든다"**는 표현이 그대로 남아 있습니다. "정리한다 / 노트를 만든다" 계열을 권합니다.

- 대안 A: "영상 보면서 되감기 그만. 단별로 정리해 드릴게요."
- 대안 B: "뜨개 영상 링크를 넣으면, 나만의 뜨개 노트가 만들어져요."

"도안" 대신 **"뜨개 노트"** 라는 자체 용어를 쓰는 것이 프레이밍상 가장 깔끔합니다.

## 4. 경쟁사 분석: 해먹으리

**추구하는 것: 뜨개질계의 해먹으리.**
영상 소스만 요리 → 뜨개로 바꾸는 것이므로, 이미 검증된 구조를 그대로 참고할 수 있습니다.

> 아래는 **조사해야 할 항목의 체크리스트**입니다. 실제 조사 결과는 확인 후 이 문서에 채워 넣으세요.

### 조사 대상
- 앱스토어 / 플레이스토어 소개 페이지 (기능 목록·스크린샷·리뷰)
- 공식 웹사이트 · 블로그 · 인터뷰 기사
- 실제 앱 사용 (영상 링크 입력 → 결과 화면 흐름)

### 확인할 것

| 항목 | 왜 중요한가 |
|---|---|
| 영상 → 레시피 변환 결과의 **구성 요소** | Knotty의 카드 구성과 1:1 대응. 무엇을 넣고 무엇을 뺐는지 |
| **창작자 표기** 방식 | 저작권 대응의 실제 사례. 어떻게 표기하고 어디로 링크하는지 |
| **저장 / 스크랩 / 폴더** 기능 | "내가 만든 도안"(P3-1) 설계 참고 |
| **검색 · 인기 · 카테고리** 구조 | 게시판(P3-2) 설계 참고 |
| **재료 → 구매 연결** 방식 | 수익 모델의 핵심. 어떤 형태로 붙였는지 |
| 광고 노출 위치와 밀도 | 사용성을 해치지 않는 선 |
| 유료 기능 유무 | 무엇까지 무료로 풀었는지 |
| **원작자와의 관계** | 제휴? 무단? 항의 사례가 있었는지 — **가장 중요한 조사 항목** |

### 요리 vs 뜨개의 차이 (그대로 베끼면 안 되는 부분)

| | 요리 | 뜨개 |
|---|---|---|
| 결과물 길이 | 10~20 스텝 | **수십~수백 단** — 표·스크롤 설계가 훨씬 중요 |
| 정확도 요구 | 대략 맞으면 됨 | **코수가 1개 틀리면 편물이 틀어짐** → 검증 로직이 핵심 (P1-3) |
| 유료 상품 존재 | 레시피 판매는 드묾 | **도안 판매가 보편적** → 저작권 리스크가 훨씬 큼 |
| 소비 방식 | 한 번 보고 끝 | **몇 시간~며칠에 걸쳐 반복 참조** → 진행 상황 저장(체크박스)이 핵심 기능 |

> 세 번째 줄이 Knotty가 해먹으리를 그대로 따라 할 수 없는 이유이고,
> 네 번째 줄이 Knotty가 해먹으리보다 **더 잘할 수 있는 지점**입니다.
> 단별 체크박스는 이미 구현되어 있으니, **진행 상황을 저장**해서 다음에 이어 뜨게 만드는 것이 차별점이 됩니다.

## 5. 수익화

**도안으로 돈을 벌지 않는다.** 준비물 구매 연결과 광고로 법니다. (2번 원칙 ⑤)

### 5-1. 준비물 → 구매 링크 (1순위)

준비물 섹션의 모든 항목을 클릭 가능한 구매 링크로 전환합니다. 사용자가 실제로 필요로 하는 순간이라 전환율이 가장 높은 자리입니다.

| 항목 | 링크 생성 방식 |
|---|---|
| 실 | ① 영상 설명란의 구매 링크 → ② 없으면 `실 이름 + 채널명` 검색 (채널 운영 쇼핑몰) → ③ 그래도 없으면 일반 검색 |
| 바늘 | `needle.type` + `needle.size`로 해당 호수 상품 링크 |
| 부자재 | 단수링·돗바늘 등 `accessories` 항목별 링크 |

### 5-2. 쿠팡 파트너스

뜨개 인기템 리스트를 도안 하단에 노출. 도안에 실제로 쓰인 부자재와 매칭하면 자연스럽습니다.
※ 제휴 링크에는 **"이 링크를 통해 구매 시 수수료를 받을 수 있습니다"** 고지가 필요합니다.

### 5-3. 뜨개샵 배너 (중장기)

바늘이야기 · 앵콜스 · 솜솜뜨개 등 국내 뜨개샵 배너.
**협상하려면 숫자가 먼저 필요합니다** — 월 방문자, 도안 조회수, 링크 클릭률.
→ P3-2(조회수)와 클릭 추적이 선행되어야 착수 가능한 단계입니다.

### 진행 순서

```
P3-2 조회수/클릭 지표 확보
      ↓
5-1 준비물 구매 링크 (수익 발생 시작)
      ↓
5-2 쿠팡 파트너스
      ↓
5-3 뜨개샵 직접 제휴 (지표를 근거로 협상)
```

## 6. 홍보

**유튜브 댓글이 1차 유입 경로입니다.**

원래 하고 싶었던 것이 "댓글에 누가 정리해 둔 요약"이므로, 그 자리에 Knotty가 직접 들어가는 것이 가장 자연스럽습니다.

1. 도안 카드 → "댓글용 텍스트 복사" 버튼 (P2-3)
2. 단별 요약을 유튜브 댓글 서식(표 없이 한 줄씩)으로 변환
3. 말미에 `— scripted by Knotty 🧶 (링크)`
4. 영상에 댓글로 게시 → 같은 영상을 보는 사람들이 유입

> 주의: **정리 내용 자체가 유용해야** 합니다. 광고처럼 보이면 삭제되고 채널주와의 관계도 나빠집니다.
> 댓글 텍스트는 짧게, 링크는 한 줄로. 그리고 **창작자가 싫어하면 즉시 지웁니다.**
